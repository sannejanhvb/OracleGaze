# OracleGaze

A simple OracleGaze Framework for Auto scaling capabilities.

With OracleGaze, you get a lightweight tool that stays out of your way.

**What you get**

- A simple OracleGaze Framework for Auto scaling capabilities

## Key Features

- A simple OracleGaze Framework for Auto scaling capabilities

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/OracleGaze.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure OracleGaze, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
